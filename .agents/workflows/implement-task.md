description: Đọc bản đặc tả kỹ thuật (Task Spec) trong CURRENT_TASK.md và code chính xác theo từng mục
---

1. Đọc toàn bộ file `README.md` và file `CURRENT_TASK.md` ở thư mục gốc của dự án.
2. Phân tích danh sách các file C# cần tạo hoặc chỉnh sửa được liệt kê trong `CURRENT_TASK.md`.
3. Thực hiện viết code từng file một theo đúng 100% tên Class, tên thuộc tính, công thức toán học và chữ ký hàm (Method Signature) đã được chỉ định trong `CURRENT_TASK.md`. Tuyệt đối không tự ý lược bỏ code hoặc để lại comment `// TODO`.
4. Kiểm tra lại để đảm bảo các file trong `Scripts/Core` không chứa `MonoBehaviour` và đúng namespace `CrownlessWarband.*`.
5. Sau khi tạo xong toàn bộ các file trong `CURRENT_TASK.md`, tóm tắt ngắn gọn các file đã tạo để người dùng kiểm tra trên Unity Editor.
